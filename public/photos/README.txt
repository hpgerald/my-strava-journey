Photographs for the story go in this folder.

Each place on the site that waits for a photo shows a placeholder with a slot
name, for example "kili-summit". To fill it:
  1. save the picture here (JPG or WebP, about 2400 px on the long side);
  2. in src/lib/photos.js set that slot's `file` to the file name and write a
     short `alt` that says what the picture shows.
The slots are listed in src/lib/photos.js.
